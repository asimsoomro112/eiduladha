# Saniya Eid Adha

A private Eid ul Adha gift built with Next.js, React, Tailwind CSS, GSAP, and Framer Motion.

## Local Development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production Check

```bash
pnpm lint
pnpm build
```

## Vercel

The project is ready for Vercel. Vercel should use:

- Framework preset: `Next.js`
- Install command: `pnpm install --frozen-lockfile`
- Build command: `pnpm build`
- Output directory: Next.js default

No environment variables are required.
